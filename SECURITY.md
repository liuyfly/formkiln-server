# Security Policy

## Supported versions

Formkiln is in early development. Security fixes are made on the latest release only.

## Reporting a vulnerability

**Do not open a public issue for security problems.**

Report vulnerabilities privately through GitHub: go to the **Security** tab of the affected repository and choose **Report a vulnerability**
([formkiln](https://github.com/liuyfly/formkiln/security/advisories/new),
[formkiln-server](https://github.com/liuyfly/formkiln-server/security/advisories/new)).

Please include the affected component and version, reproduction steps and the impact you observed. We aim to acknowledge reports within 5 working days and will keep you informed until the issue is resolved. We are happy to credit reporters in the advisory.
